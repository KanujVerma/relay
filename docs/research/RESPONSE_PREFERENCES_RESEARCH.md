## Local source verification

Read actual `generated_answer.py`, `conversation_context.py`, SessionHost, the Model's actual typed/audio/held-context ingress/publication and current Settings. The current prompt's all-strings-are-data policy means a new custom-instructions field requires an explicit carefully bounded policy seam. Its 32 KiB prompt budget and current output/QA/verified-personal authority remain binding. A guide cannot supply missing starter code, schema, requirements or verified history. Default automatic task/stage routing remains the recommended behavior.

Focused baseline command, from this isolated clone:

```sh
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=tests:. /private/tmp/relay-root-current-runtime/venv/bin/python -m unittest tests.test_contextual_scenarios tests.test_contextual_answers
```

**15 cases pass in 0.044 s**, exact unchanged source, synthetic completions only. This includes three engineer coding generations for three accepted questions and five feature-stage generations for five questions; no classifier call. An earlier invocation without `PYTHONPATH=tests:.` failed importing the test helper; the path-corrected run above passed without source changes. Log `/private/tmp/relay-response-preferences-baseline-context.log`. These tests demonstrate existing routing/context/QA contracts, not live answer usefulness or a new preferences implementation.

No private files, account/Keychain, capture/permissions, audio/model load, new public dependencies, real model calls or target application execution were used. Static REA client inference is labelled separately from official documentation and actual Relay runtime/test evidence. The proposal introduces no copied/invoked upstream component, so no new package/model/license notice is needed at this design stage; retain these source/license references for implementation review.
