# Product runtime dependencies

Research and pins checked2026-10-23. The build retains installed distributions' actual license files and the standalone Python input's component notices; a top-level license name alone is not sufficient for nested native libraries. The generated helper Resources/notices and package dist-info/license directories carry those texts, while build-provenance.json records source state, both lock hashes and exact dependency/input versions.

- **CPython3.14.9**, PSF license and historical notices: [official release](https://www.python.org/downloads/release/python-3149/), [source ead82c07db1f111d613926ed1b6667411d768125](https://github.com/python/cpython/tree/ead82c07db1f111d613926ed1b6667411d768125). Build input is Astral Python Standalone Builds20261021 at0c5e581b54a4736cdbbe68bdd6d7e571a1dca11e, GIL-enabled arm64 stripped install-only artifact; exact URL/size/SHA256 are in python-build.json. No system interpreter is installed or changed. Existing host3.14.5 was deliberately not selected as the product's patched input.
- **PyInstaller6.22.3**: [pinned source/license](https://github.com/pyinstaller/pyinstaller/blob/v6.22.3/COPYING.txt). GPL2-or-later with its bootloader/loader distribution exception; its embedded runtime hooks are Apache2.0. The tool/unchanged bootloader is invoked, not copied into Relay source. Standard build-time hooks are part of the packager; their licenses must not be confused with the dependency code they collect. Exact build transitive versions/hashes are in build-requirements.lock.
- **HTTPX0.28.1** BSD3-Clause; **PyJWT2.15.1** MIT; **cryptography50.0.2** Apache2.0 OR BSD3-Clause, with its bundled native-component notices. These are dependencies of the existing reviewed HTTP/OIDC ports; this lane changes no auth behavior or account entitlement.
- **Docling Slim2.142.0**, **Docling Core2.104.0**, **Docling Parse7.23.0**, **python-docx1.2.0**, **defusedxml0.7.1**: MIT, verified against pinned package metadata/source. The existing NativePdf and strict paragraph-DOCX adapters are invoked unchanged. **pypdfium2 5.14.0** uses BSD3-Clause/Apache2.0 with separate PDFium/transitive notices. Preserve its distributed license files. Model/OCR/VLM extras and comparator-only MarkItDown/Magika/ONNX stacks are excluded.

All production transitives, including Core's declared pandas/Pillow/schema/Pydantic dependencies, are pinned in runtime-requirements.lock. The lock was resolved with uv0.13.1 for CPython3.14.9/arm64 and MACOSX_DEPLOYMENT_TARGET15.2 using binary wheels only. uv's cross-platform macOS default is13.0, which is below the approved Docling Parse wheel's14.0 minimum; the explicit product target resolves that difference. The final product must audit every collected native architecture, minimum OS, install name and signature.

Read upstream loader and tests before design: PyInstaller's pyiboot01_bootstrap.py and functional basic/environment/symlink/ctypes tests; Docling2.142.0 project metadata, DocumentConverter and NativePdf pipeline; existing approved Relay converter tests/implementation. Upstream tests were inspected, not executed. Py2app and raw standalone-Python shipment were considered; an onedir frozen console helper fits the existing Swift-owned child/pipe/reap contract without onefile extraction/parent ownership. No proprietary source, private user content, credentials or speech weights belong in this runtime.

The matching63,579,089-byte full Python build archive (exact URL/SHA in python-build.json) supplies authoritative PYTHON.json and component license texts, not a second shipped interpreter. It identifies the built-in OpenSSL3.5.9/Apache2, libffi/MIT, libedit/BSD3, liblzma/0BSD, SQLite/Zlib and other static components. Their complete supplied license texts are retained; the full build/object tree is not packaged. Community Hooks2026.9 was also inspected: standard build hooks are GPL2-or-later, embedded runtime hooks are Apache2.0. In particular the crypto OpenSSL runtime hook's Apache2 header and its repository license distinction were verified.

The final helper uses stock PyInstaller BUNDLE(COLLECT), preserving the console onedir process and the tool's macOS code/data separation and crosslinks. The bootloader's generic helper icon is part of its exception-covered bootloader directory. No proprietary interface/assets were copied. Native SwiftPM source pins and existing notices remain unchanged; the actual two public resource bundles are copied into the outer app's Resources. All copied native code is audited/signed, without claiming Developer ID, notarization or Gatekeeper distribution approval.
