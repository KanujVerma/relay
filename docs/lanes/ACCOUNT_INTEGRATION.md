## Frozen consumer seams

`AccountStorage(sharedDirectory:URL, keys:ProfileKeyProvider = KeychainProfileKey(purpose:.chatGPTCredentials))` is inert. Its explicit `controlBootstrap(generation:createKey:)` first creates/validates the supplied fixed shared Relay parent as owned0700, then its Accounts child as owned0700. It never recursively creates unknown parents, repairs existing permissions, follows a leaf symlink or replaces a missing key for existing ciphertext. The product factory must supply the same fixed ApplicationSupport/Relay root as ProfileVault. No user-selected credential path, legacy file import or profile consent is involved.

`AccountSecretBootstrap` has no public initializer or Codable interface and redacts normal/debug descriptions. `frame()` returns the private first BE32 frame for an inherited pipe only. It must never enter argv/environment, public status, a temporary file or diagnostics. The packet's public generation/registration fields help the native caller bind its original private selection; they do not contain a verified person/account identity claim.

`AccountPort.perform(AccountRequest, authorization:@Sendable(AccountAuthorization) async->Bool)->AccountResponse` and `close()` are the injected interface. `PipeAccountPort(python:repository:bootstrap:pythonArguments:operationTimeout:)` is the actual child implementation. Product factory uses an empty argument prefix and the resolved bundled interpreter/root; only tests provide a synthetic launcher. The port appends exactly `-m relay_spike.account_bridge`, writes the private bootstrap first, and owns a concurrent strict reader and serialized bounded writer. One private URL effect may call the injected native browser opener for the matching pending request; a false result stops/reaps the child. Successful connect completion waits for that effect's result. No private URL is published as account status.

The32-frame/256KiB writer, three-second frame deadlines, bounded request waiters,512 native seen UUIDs/eight completed replies, exact action/revision binding and real prelaunch child-exit receipt fail closed. IO is joined before original descriptors close. Cancelled Swift tasks never certify process cleanup; close sends TERM, escalates after500ms and still waits for Foundation's actual exit receipt. A completed `close()` permanently retires that port. Public readonly `exitConfirmed` is testable host-owned process state, never model/JSON authority.

`@MainActor AccountController` takes storage, `portFactory`, **actual old-session-helper `retireInference:()async throws->Void`**, synchronous native browser opener, saved AI preference/persistence closure and actual idle predicate. The predicate must read base capture/idle-helper lifecycle, not recursively depend on this controller's busy/canMutate state. It exposes real async restore/connect/reconnect/enablePlan/select/signOut/refreshModels/setAIEnabled/acknowledgePlanNotice/cancel/close actions. Constructor and view rendering do no IO. Mutation immediately retires the private selection, then awaits the old inference helper's actual stop/reap barrier, closes the prior control child, and obtains a new native generation/bootstrap. It checks lifecycle/idle/current request again after every await before using replies. Cancel joins the actual original operation and its control child; cancellation-ignoring work cannot restore a selection. Closing the controller is final, intended for app shutdown/replacement, not hiding Settings.

`restore()` performs local status, then real select/current catalog under a fresh generation when the saved AI preference is on and the selected grant is available with plan permission. It does not force a browser reconnect. Status metadata alone never creates inference authority. Identity-only sign-in remains plan-disabled with an explicit Enable action; there is no consent/reconnect loop. Successful explicit connect/select with plan permission saves the AI preference. The first visible current catalog model is selected automatically in server order; there is no required front-facing model choice or fixed entitlement.

`inferenceSelection:AccountInferenceSelection?` is a non-Codable native object with a private initializer and immutable registrationID/generation/model. Root consumes `owns(originalSelection)` for currentness and `sessionBootstrap()` for the private oauth_session first frame. Account operation/AI disable/close retires the original selection. Dismissing the local first-use notice does not change inference authority or Personal Brain consent. Encrypted selection/generation/scope and actual bearer are independently revalidated by ProtectedAccountSession at use; this object is not a token/account entitlement attestation.

`AccountSettingsView(controller:)` consumes these actual commands: Continue with ChatGPT, saved-registration use/reconnect, explicit plan enable, AI preference, automatic model status/refresh, sign-out/cancel, and the first-use plan explanation/acknowledgement. No usage estimate, fake model picker, profile approval or private URL is shown. The [official UI guidance](https://developers.openai.com/siwc/ui-ux-guidelines) and its link target confirm `https://chatgpt.com/settings/usage`; [the sign-in page](https://developers.openai.com/siwc/website) shows the plain Continue with ChatGPT format.
