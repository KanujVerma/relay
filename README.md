# Relay

**Native, local-first macOS personal interview copilot.** Relay is being designed to detect questions in authorized interviews, retrieve verified personal/job context, and surface fast, accurate, concise talking points. Continuous learning improves the assistant's answers and relevance, not a generic tutoring curriculum.

**Status (2026-10-22):** Slice 00 contract and 26 synthetic fixtures merged. Slice 00B documents the complete architecture and new-agent handoff. The Slice 01A OAuth/Responses CLI is **implemented and has a successful user-reported local OAuth + gpt-6.1-sol streamed response**; microphone and selected-app PCM capture spikes have merged, while real Mac capture validation, local ASR and the macOS app remain pending. Issue #29's synthetic PDF/DOCX converter evaluation merged in [PR #34](https://github.com/KanujVerma/relay/pull/34), with both CI checks passing. A post-merge Codex review identified a secondary DOCX relationship gap; the follow-up is fixed in merged [PR #36](https://github.com/KanujVerma/relay/pull/36) with both CI workflows passing and the final Codex review clear. Repository is public by owner's choice; never commit private data or credentials.

## Slice 01B-B2 development: one synthetic real-OAuth QA run
The prototype `live-qa` command uses the current account's authorized ChatGPT-plan OAuth scope, but **does nothing remotely unless `--execute` is passed**. See [docs/RUN_LOCAL_LIVE_QA.md](docs/RUN_LOCAL_LIVE_QA.md). It applies existing deterministic QA to one of two pre-reviewed D02/E09 synthetic questions, never verified personal data, and surfaces only exact allowlisted complete `final_unverified` text. Technically reasonable paraphrases are withheld until a trusted classifier is implemented. No real-user Mac execution, production reliability, first-useful latency, semantic correctness, native audio or session overlay has been validated in this PR.

## OAuth renewal (Slice 01A-R, merged PR #31)
The existing `relay_spike` sign-in still needs `PyJWT[crypto]`. Install it inside your active virtual environment using `python3 -m pip install -r requirements-spike.txt`. Merged [PR #31](https://github.com/KanujVerma/relay/pull/31) closes issue [#30](https://github.com/KanujVerma/relay/issues/30) and implements near-expiry refresh-token rotation with a protected local inter-process lock, terminal revocation handling, and no API-key fallback.
