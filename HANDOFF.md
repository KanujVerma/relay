## Foundation and non-goals
Relay is a local-first native macOS interview copilot for **authorized assistance**, not a tutoring app. Primary target roles are Epic Software Developer and junior AI/BI/analytics. It should relay concise technical and verified personalized talking points, review response quality, recognize corrections/follow-ups and improve over time.
- **Personal Brain** stores verified first-person history and source provenance; never invent skills or contributions.
- **Learning Memory** tracks observed question patterns and explicit assistant corrections; it never promotes unverified speech/model text into personal facts.
- ChatGPT OAuth authentication is independent from any Drive/GitHub app connectors or ChatGPT Memory.

## Still unimplemented
No native SwiftUI app, hardware-verified Zoom capture, local ASR, diarization, live question detection, **production Personal Brain with approved user imports**, Drive/GitHub import, production QA pipeline or continuous learning runtime. A synthetic-only Personal Brain SQLite prototype has merged in PR #18, but it is **not** a shipping user-profile store. ## Privacy and CI
Repository is PUBLIC until the owner chooses otherwise. Never commit credentials, OAuth callbacks, recordings, résumés or private interview source content even after going private. Linux CI performs offline fixture/doc/tests only; the public-repo macOS audio workflow builds and runs synthetic checks without microphone/system-audio permission prompts. GitHub Codex PR reviews are tracked usage and should be explicitly verified, not assumed free or finished just because a comment was submitted.
