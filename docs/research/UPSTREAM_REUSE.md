# Source research for the integrated session

Reviewed 2026-10-23. These findings support a proposed design; no new upstream code has been copied and no new runtime dependency adopted during this planning effort. Existing Relay capture/ASR dependencies remain governed by their own notices. Inspect actual source and tests, not project popularity or README performance claims. Recheck pins and licenses before adoption.

## Important findings to carry forward

- Current EOU wire has 13 exact fields; old scratch prose saying 14 was a counting error, not a schema change.
- PR49's inspected head already emits blank finals. Old main prose describing them as dropped is historical; do not duplicate an existing fix.
- PR46 already supplies text-free `remote_speech_started` suspension. The remaining issue is proven identity/range association with native VAD/ASR, not the absence of a Python state operation.
- A native packet timestamp or late-created ASR segment counter is not proof of decoded-word alignment. Propagate actual consumed-range provenance or withhold ambiguous associations.
- VAD probability, schema validity, a source-ID string and completed SSE are different kinds of evidence. None may be relabeled as transcript confidence, personal verification or technical correctness.
- Cross-process display requires native authority at UI commit. Python's same-process card identity and lock cannot be serialized into that guarantee.
- The synchronous SSE transport may remain blocked after local cancellation. Any claim of prompt interruption recovery needs a tested transport choice; suppression of a stale answer alone does not prove resources were released.

## Before copying or adopting

For each selected component record exact upstream URL/ref, license/notice, copied files or invoked API, modifications and purpose, dependency/model/platform requirements, local negative tests and actual integration measurements. State whether code is reused, behavior is adapted, or source is only a reference. Keep private user material and model artifacts outside Git. New architecture remains proposed until its design and acceptance are agreed.
