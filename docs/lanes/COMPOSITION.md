## Approved composition behavior

One bounded ordered pump may hold a remote EOU for at most 1.5 seconds. A newer onset/control cancels optional work and immediately forwards the original EOU without context before the later event. Original global sequence/session/request/epoch/generation is never restamped. Queue overflow retires, and late OS completion cannot send after retirement. At most one OCR frame precedes automatic EOU; explicit manual Help may use one selected-text frame with priority over OCR. The helper stages syntax only for at most 2 seconds; its actual validated current Request must supply the original native envelope before any provider ingestion. Late context cannot attach after generation starts.

Selected text has a separate strict wire schema, source application/PID/launch identity, consent UUID, capture time and observation UUID. It uses existing generic `screen_text` task kind with explicit `selected_accessibility_text` provenance, never `local_ocr` or biography authority. Selected text has deterministic priority over OCR. Actual used source/provenance appears in the app. OCR answers require one bounded re-observation followed by synchronous original native lease plus coordinator ownership checks before the panel's own atomic commit. The image route stays off.

Help is a separate manual request referencing an active authorized native session, fresh UUID/newer native lease and exact latest forwarded audio sequence anchor. It reruns only the current accepted verbatim question and semantic token; it never fabricates audio, ASR text/finality or timestamps. With no current question, the visible result is Ask a question first. Pause ends actual capture admission and clears ephemeral dialogue/task state; resume starts a fresh native session only after actual old ownership quiesces. Protected preparation and explicit source/shortcut consent may persist.
